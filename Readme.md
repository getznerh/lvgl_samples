Based on the excellent work of kdschlosser at
https://github.com/lvgl-micropython/lvgl_micropython
I have compiled examples for various ESP32S3 modules with different displays, all based on LVGL Micropython versions compiled with kdschlosser's MAKE modules.

The examples also work under WSL2 and the SDL2 display library.

Further details can be found in the few example files.

The Micropython firmware is created under Windows WSL2 with Ubuntu 22.4.

The descriptions and comments are mostly in German.
Thanks to Google Translate, understanding should be no problem!
